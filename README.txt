# تطبيق إدارة فريق الخماسي
نسخة أولية كاملة تعمل كتطبيق ويب قابل للتثبيت على الهاتف (PWA).
البيانات تحفظ محلياً على الجهاز عبر LocalStorage.
الوظائف: اللاعبون، الحضور والغياب، التمارين، المباريات الودية والرسمية، أهداف اللاعبين، الإصابات، الأداء، السلوك، التقارير والتقييم العام، وتصدير/استيراد البيانات.
للاستخدام كـ PWA على الهاتف: ارفع الملفات على استضافة HTTPS، ثم افتح index.html من المتصفح واختر إضافة إلى الشاشة الرئيسية.
